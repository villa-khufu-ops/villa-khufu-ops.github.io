Villa Khufu - one program on the reception laptop
==================================================
* The program is the app AND the kitchen printer together.
* Open the app from the "Villa Khufu" icon on the Desktop.
* Closing the window does NOT stop kitchen printing; it keeps printing in the background.
* Windows starts it automatically and checks every 5 minutes.

Install / update:
 1) Extract this zip INTO the old "VillaKhufu-Print" folder (replace files).
 2) Double-click 1-SETUP.bat  (log in once if asked, then close the window).
 3) From now on use the "Villa Khufu" icon.

Stop printing: print-station-stop.bat   |  Start again: 1-SETUP.bat

Reception invoices (USB printer): the app sends the invoice straight to the USB receipt printer.
If it picks the wrong printer: create rec-printer.txt in this folder with the exact printer name inside.
